Description

              This project is a machine learning-based system that predicts the likelihood of heart disease using patient medical data. It analyzes key health features such as age, chest pain type, blood pressure, cholesterol level, and other clinical parameters to make predictions.

Multiple machine learning models like Logistic Regression, Decision Tree, and Random Forest are implemented and compared. The Random Forest model provides the best accuracy and is used for final prediction.

The project also includes data visualization and exploratory data analysis (EDA) to understand patterns and relationships in the dataset. The final system can predict whether a patient is at risk of heart disease and also provide probability-based results.

This project is useful for beginners in data science and machine learning and demonstrates how AI can be applied in the healthcare domain.
